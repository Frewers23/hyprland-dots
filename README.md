# My Private Hyprland + Noctalia Dots

This repository contains my personal configurations for a highly customized Linux desktop experience built around **Hyprland** (Wayland compositor) and **Noctalia** (UI Shell).

## Key Features
- **Dynamic Theming:** Deep integration with Noctalia templates. The colors of the system, Neovim (LazyVim base16), and other apps automatically sync with the wallpaper palette.
- **Pixel Perfect Typography:** Global usage of `ProFontIIx Nerd Font` with disabled antialiasing for maximum crispness. Includes a custom Fontconfig fallback utilizing `Terminus` and `Cozette` to seamlessly support Polish characters (ą, ę, ł, ś, ć, itp.) which are natively missing from ProFont.
- **Optimized UI Elements:** Noctalia Control Center with semi-transparent background (glass mode) and disabled blur in Hyprland layer rules.
- **Cheatsheet Integration:** Heavily documented `binds.lua` that natively integrates with Noctalia's `keybind-cheatsheet` community plugin.

## Directory Structure
- `.config/hypr` - Window rules, keybinds, animations, and look/feel.
- `.config/noctalia` - Custom Lua configuration and CSS styling overrides for the shell.
- `.local/state/noctalia` - Main GUI settings configuration (TOML) generated by Noctalia v5.
- `.config/fontconfig` - Custom font substitution rules (`99-profont-fallback.conf`).
- `.config/kitty` - Terminal emulator configuration.
- `.config/nvim` - LazyVim customizations for dynamic Noctalia theming.
- `.config/spicetify` - Pixel font override for Spotify.
- `.config/gtk-3.0` - GTK font and dark theme preferences.
- `.config/fastfetch` - Custom system fetch configuration.

## Installation
You can automatically install everything using the included install script:

```bash
chmod +x install.sh
./install.sh
```

**Note:** Ensure you have the required fonts installed on your system (e.g., `ttf-profont-nerd`, `terminus-font`).
